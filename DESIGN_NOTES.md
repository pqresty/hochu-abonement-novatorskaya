# Принятые изменения после просмотра варианта

Оставлены только вводные мысли без отдельных плашек на компьютере и раскрывающиеся по плюсику принципы тренеров на телефоне. Подвал, карточки тренеров на компьютере, преимущества краткой версии и остальные разделы возвращены к исходному виду.

Типографика вводного блока наследуется из исходника Claude. Локальные Onest и Unbounded побайтно совпадают с файлами в исходной папке Claude. Базовые CSS-правила исходника не изменены.

`editorial.html` — текущий согласованный вариант; `index.html` — прежняя версия для сравнения. Галерея `compare.html` показывает актуальные снимки.
