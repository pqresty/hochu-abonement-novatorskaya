# Хочу абонемент · Новаторская

Версия сайта для обсуждения. Основа — Claude v42 от 19.10.2026.
На компьютере предложения студии открываются рядом с причинами прийти.

Сайт публикуется через GitHub Pages из `main:/docs`. Для подробной версии добавьте `#full`, для краткой — `#short`.

## Сборка

```sh
python3 build.py
python3 -m http.server 8765 --directory docs --bind 127.0.0.1
```

`src/site.html` — рабочая копия фрагмента v42 с исправленной иерархией заголовков и расчётами цены занятия. Стоимость абонементов сохранена. Исходная версия сохранена в первом коммите; оригинальные файлы Claude на компьютере не менялись. `build.py` готовит отдельную страницу с локальными шрифтами, фотографиями, QR-кодами, живым расписанием и картой.

На этом стенде форма подготавливает письмо в почтовой программе. Автоматической доставки заявки нет. Рабочий запуск запланирован на Тильде с приёмом заявок в Fitbase.
Метрика выключена. В странице установлен `noindex`, в `robots.txt` — запрет обхода. Это не ограничение доступа: ссылка и репозиторий публичные.

Оригинальные рабочие материалы и внутренние документы в репозиторий не входят. Права на сторонние материалы описаны в `docs/credits.html`.
